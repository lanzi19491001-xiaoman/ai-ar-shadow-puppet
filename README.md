# AI+AR 皮影小剧场 · A1 真 AR 原型

手机扫一扫皮影海报，幕布和武松、老虎落到现实桌面，隔空演一出《武松打虎》。
技术栈：MindAR（开源免费图片追踪）+ A-Frame，纯前端，无需账号与服务器。

## 文件结构

```
a1_ar_demo/
├── index.html           # 主页面（WebAR 场景 + AI 讲戏面板）
├── targets.mind         # 追踪图特征文件（已由海报编译生成）
├── poster-target.jpg    # 识别目标：皮影海报（需打印或另一块屏幕展示）
├── stage.png            # AR 幕布舞台背景板
├── wusong.png           # 武松（入场站姿，透明底）
├── wusong-punch.png     # 武松（打斗出拳，透明底）
├── tiger.png            # 老虎（入场姿态，透明底）
├── tiger-pounce.png     # 老虎（扑击姿态，透明底）
└── README.md
```

## 使用步骤

1. **展示识别目标**：把 `poster-target.jpg` 打印出来（建议宽度 ≥ 15cm，A4 打印最佳），
   或放到另一台电脑/平板上全屏显示。保证画面清晰、光线充足、无强反光。
2. **部署页面（必须 HTTPS 或 localhost）**，三选一：
   - GitHub Pages：把整个文件夹推到 GitHub 仓库，Settings → Pages → 选择分支即可，
     访问 `https://<你的用户名>.github.io/<仓库名>/`。
   - Vercel / Netlify：直接把文件夹拖进网页即可，自动带 HTTPS。
   - 本地调试：`npx serve` 后在**本机** Chrome 打开（localhost 属于安全上下文，可用摄像头）。
     ⚠️ 手机通过局域网 IP 访问时不能用摄像头（浏览器安全限制），务必走 HTTPS。
3. **手机录屏**：手机打开页面 → 允许摄像头 → 把海报对准镜头 →
   出现"剧场已降临"提示即识别成功 → 开始系统录屏：
   - iPhone：控制中心 → 录屏按钮
   - Android：下拉通知栏 → 屏幕录制
4. **演示动作**：识别后可点底部按钮：
   - 「切换场景」：武松/老虎在"入场"与"打斗"姿态间切换（打斗姿态更出片）
   - 「AI 讲戏」：弹出知识卡（流派 / 雕刻工艺 / 操纵技法），配合讲解

## 识别不稳定的排查

- 增大打印尺寸 / 保持静止几秒，让摄像头"锁定"
- 提高光线、避开反光与遮挡
- 打印时不要缩小到名片大小；手机上尽量横持、靠近目标

## 说明

- 知识卡文案为演示方向（流派 / 雕刻 / 操纵），正式讲解内容请按权威资料替换 `index.html` 中「AI 讲戏」面板文本。
- 识别目标若想换成其他图案：把新图按 `compile.mjs` 方式重编译为 `targets.mind` 即可（需 Node 环境）。
